# Runtime reference provenance

`seed1_runtime_table.md` is a byte-for-byte copy of the historical
`baseline_recovery_seed1/results/aggregate/runtime_table.md` from the project
workspace. It is included so `aggregate_runtime_table.py` can run without that
sibling repository.

SHA-256: `b2d69eb7cdeff8a195c9daf6581159b3666bba664227524220a074f407b785fa`

The table contains rounded, sampling-only seed-1 aggregate measurements. The
runtime aggregator uses only its Sieve Hipster+Train Ticket entry as a fallback
when no complete run is available; this is not a per-case archive or a new run.
The table contents and the existing fallback selection are unchanged.
